Cara baca: semua harga dalam USD, penutupan dihitung per hari UTC (00:00 UTC). M1-M4 = harga penutupan 4 minggu terakhir (M1 = 4 minggu lalu, M4 = minggu lalu), angka % = perubahan dibanding minggu sebelumnya. Nama hari = 7 hari terakhir, % = perubahan dibanding hari sebelumnya. Avg 7h = rata-rata 7 hari terakhir, Avg vs open = rata-rata itu dibanding harga pembukaan minggu. - = data tidak tersedia di sumber gratis (detail di bawah).
Metodologi & keterbatasan data

Sumber: CoinGecko Free API (daftar top 500, harga live, market cap, volume, sparkline 7 hari) + API publik Binance/MEXC/Gate (candle harian asli & harga hari listing pertama). Semua gratis, tanpa API key.

Kenapa bukan CoinGecko saja: API gratis CoinGecko menolak permintaan data lebih tua dari 365 hari (error 10012), jadi riwayat mingguan dan harga hari launch diambil dari exchange.

Harga hari launch = penutupan hari pertama coin tercatat diperdagangkan di Binance/MEXC/Gate (bukan harga ICO/pre-market). Untuk coin yang lebih baru dari 1 tahun, CoinGecko memberi hari pertama yang sebenarnya.

Tanda - muncul kalau coin tidak punya pasangan USDT di Binance/MEXC/Gate (umumnya stablecoin & tokenized fund), kalau ticker-nya bentrok dengan aset lain di exchange (datanya dibuang, bukan dipakai), atau kalau coin-nya memang baru listing sehingga harga 1 tahun lalu belum ada.

Validasi otomatis tiap update: semua kolom % dihitung ulang dari kolom harga (harus cocok), dan harga di halaman ini dicocokkan dengan ticker live Binance untuk mendeteksi ticker yang salah pasang.

Update: harga, market cap, volume, dan kolom % di-refresh otomatis tiap jam (cron sistem menit ke-7 tiap jam, UTC) memakai 2 call CoinGecko Free API. Penutupan harian asli dari exchange, file Excel, verifikasi %, dan pengecekan coin baru dijalankan tiap hari 00:10 UTC (07:10 WIB). Angka "Data per" di atas adalah waktu build terakhir.
